# 內外圈整合圖說明

圖的可編輯 Mermaid 原始碼：[inner-outer-integration.mmd](/F:/VirusWeb/docs/inner-outer-integration.mmd)。

主圖分為兩條操作鏈路，匯入同一場 Unity 遊戲：
- 內圈：右 Joy-Con → BetterJoy → Windows 滑鼠移動 → Unity 攝影機旋轉。
- 外圈：手機網頁 → Firebase 指令資料 → Unity 指令檢查與佇列 → 病毒／胃液干擾。

在線回報獨立呈現，不以長回線繞過主圖；最後一列整理支援模組。
請將在線回報的最終結果理解為主圖網頁操作檢查的輸入，不是另一套獨立系統。

實作範圍依 2026-10-14 對三個專案資料夾的檢查：
1. Unity 目前啟用自動前進，換線與 WASD 腳本在儲存場景中停用。
2. 攝影機旋轉已實作；沒有找到射擊腳本，ZL→左鍵只作使用者描述的映射，以虛線表示。
3. 「病毒狂暴」的實際效果是新增一隻病毒，尚非提高病毒速度。
4. 「胃液遮擋」已綁定 OBSCURE_VISION；「準心干擾」仍未綁定指令。
5. 網頁發送成功表示資料庫寫入成功，沒有 Unity 執行完成 ACK 回傳。
6. 地圖生成器對絨毛與食物殘渣使用物件池，病毒與胃液未池化。
7. 網頁本機傾斜視差與 Joy-Con 的遊戲瞄準是不同流程。

本次只整理架構圖，沒有更動遊戲、網頁或 BetterJoy 設定。
